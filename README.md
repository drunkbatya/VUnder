# VUnder

IOS app inspired by (closed source :-(((9() [vkmp3mod](https://github.com/egormetlitsky/vkmp3mod-builds). Very simple VK client but it works.

## Building
You probably need to have a valid Apple Developer ID
### Xcode
Just open app, connect your device and tap Product->Profile
### Cli
```bash
cp local.mk.example local.mk
# fill local.mk with your data
make resolve
make ipa
make install
```
